# My Hero Academia — An Encyclopedia

*A structured reference guide to 僕のヒーローアカデミア (Boku no Hīrō Akademia), covering the story behind the anime, Seasons 1–5, the full cast, production trivia, and a power-scaling analysis.*

---

## About This Project

This encyclopedia documents the first 113 episodes of the *My Hero Academia* anime and the manga they adapt, with reference to the completed series where later events change how earlier arcs should be understood.

**Scope**

| | |
|---|---|
| **Anime covered in detail** | Seasons 1–5 (113 episodes, 2016–2021) |
| **Characters profiled** | 127+ across seven groups |
| **Manga reference** | 430 chapters, 42 volumes (2014–2024) |
| **Language** | English |
| **Format** | Markdown documents |

**A note on spoilers.** The [Seasons](02-seasons/README.md) and [Characters](03-characters/README.md) sections stay largely within Seasons 1–5, flagging later developments where necessary. The [Tier Lists](05-tier-lists/README.md) and parts of the [Villains](03-characters/league-of-villains.md) page cover the full series and contain major spoilers, which are marked at the top of each file.

## Quick Reference

### The Premise in One Paragraph

Four generations before the story begins, a glowing baby is born with a superpower. Within decades, powers called **Quirks** spread to roughly **80% of humanity**. Society adapts: heroes become a licensed profession ranked on a public chart, agencies operate as businesses, and schools like **U.A. High School** train the next generation. **Izuku Midoriya** is born into the powerless 20% — and is chosen by the world's greatest hero anyway.

### Key Dates

| | |
|---|---|
| Manga debut | July 7, 2014 (*Weekly Shōnen Jump*, Issue 32) |
| Anime debut | April 3, 2016 |
| Manga conclusion | August 5, 2024 (chapter 430) |
| Final volume | December 4, 2024 (volume 42, with the 38-page epilogue) |
| Anime conclusion | December 13, 2025 (episode 170) |

### The Central Conflict

| | |
|---|---|
| **One For All** | Power **given** across nine generations. Represents inheritance, trust, and self-sacrifice. |
| **All For One** | Power **taken** from others and hoarded. Represents accumulation, domination, and treating people as resources. |

The entire series is these two ideas fighting each other — across a century, and eventually across a single family bloodline.
